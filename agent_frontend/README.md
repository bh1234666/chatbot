# bot Agent Frontend

本目录是当前后端的本地 agent 前端。对外助手名称统一显示为 **bot**；后端内部仍可能保留 `environment` 字段和文件名以兼容旧接口。

当前实现是无依赖静态前端：

- 账号创建、切换、改名、本地删除。
- 同账号多存档，存档可绑定项目目录，也可留空作为普通 bot 模式。
- 会话副本，可并列维护同一项目的不同对话窗口。
- 同一账号、同一后端 archive/group 的窗口会做本地运行协调，避免重复撞后端并发锁。
- 通过 `/v1/agent/projects` 同步后端 archive/group/project 映射。
- 通过 `/v1/chat/stream` 做 POST SSE 流式对话。
- 中断任务、插入当前任务、消息队列自动续跑。
- 插入策略：只注入当前任务，或注入后自动排入下一轮 follow-up。
- 队列编辑、上移、下移、删除、清空。
- bot 文件区上传、上传进度、刷新、附加、预览、下载、删除。
- 支持拖放上传和剪贴板粘贴文件上传；上传失败会保留可见失败项。
- 文本、图片、PDF、音频、视频文件预览。
- 工作流侧栏实时显示主进程、helper、工具和命令事件，支持搜索、类型折叠和节点详情。
- 工作流可导出 JSON 或 Markdown。
- 命令级中断入口。
- 启动恢复后端项目列表、活跃任务和最近监控历史。
- 多窗口本地状态同步。
- IndexedDB 持久化，保留 localStorage 兼容兜底。
- 快捷任务模板，可快速填入常见工程、文件、对话任务；右键模板可加入队列。
- 当前 transcript 搜索和匹配高亮。
- 导出 Markdown、导出/导入前端状态、清理本地数据。
- 设置后端地址、监控流、插入策略和工作流保留数量。
- 项目目录面板：查看项目树、搜索项目文件、预览文本/Office/PDF 文件抽取文本。
- 项目命令运行入口：在绑定目录下运行受后端风险策略约束的命令，默认禁用 GPU。
- Run 快照刷新：通过 trace 拉取最近监控历史，补回刷新或断线期间的工作流事件。
- 停止并清队列：同时请求中断当前任务并清空当前窗口本地队列。

## 界面功能速览

### 左侧栏

- **账号**：创建、切换、改名或删除本地账号。账号用于隔离不同用户的存档、文件和前端状态。
- **存档**：同一账号下可以有多个存档；每个存档可以绑定一个项目目录，也可以留空作为普通 bot 对话。
- **新窗口**：复制当前存档为新的本地对话窗口，用于并行推进同一项目的不同任务。
- **对话搜索**：只搜索当前 transcript，并在主区高亮匹配内容。

### 顶部工具栏

- **侧栏 / 工作流**：显示或隐藏左右侧面板。
- **恢复 / 同步**：从后端恢复项目、活跃任务、监控历史，或同步当前存档与后端映射。
- **目录**：设置当前存档绑定的项目目录；为空时使用普通 bot 模式。
- **项目 / 文件 / 产物 / 设置**：分别打开项目目录面板、bot 文件区、bot 产物区和前端设置。
- **中断 / 停止并清队列**：中断当前任务；后者还会清空当前本地队列。

### 主对话区

- **快捷模板**：左键填入输入框，右键加入队列。
- **上传文件**：上传到 bot 文件区，不写入项目目录；发送前可附加或撤回。
- **超长输入**：输入超过前端阈值时会先提示确认；确认后自动转成 `.txt` 文件上传并附加，本轮只发送短指令让 bot 读取对应文件。
- **加入队列**：当前任务结束后继续发送；可切换自动/手动。
- **插入当前任务**：任务运行中插入用户消息，进入中途介入流程。
- **发送模式**：选择默认发送、加入队列或插入。

### 右侧工作流

- **详细 / 简洁**：详细模式按主进程和 helper 分层；简洁模式按时间一行一条显示最新动作。
- **导出 JSON / Markdown**：导出当前工作流用于调试或复盘。
- **刷新 run**：用 trace 从后端补回断线或刷新期间的监控事件。
- **节点展开 / 收起**：查看 helper 子步骤、工具进度和流式内容。

### 文件与产物

- **文件区**：管理上传给 bot 的输入文件，可附加、预览、下载、复制路径/URL、总结、提取、生成报告或删除。
- **产物区**：只显示 bot 生成并推送的可交付文件，可预览、下载、复制 URL 或路径。

### 项目面板

- **目录树**：查看绑定项目目录，可按相对目录刷新。
- **搜索**：搜索项目文件内容或路径，点击结果可预览。
- **运行**：在绑定项目目录下运行命令，受后端风险策略约束。
- **Diff / 解释 diff**：查看项目文件差异，并把 diff 填入输入框让 bot 分析。

所有按钮现在都有鼠标悬停说明；悬停后浏览器会显示详细用途，屏幕阅读器也能读取对应 aria-label。

启动：

```powershell
python agent_frontend\serve_frontend.py --port 8765 --backend 127.0.0.1:8000
```

打开：

```text
http://127.0.0.1:8765/
```
